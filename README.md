# 🤖 JARVIS Face Detector

A real-time face detection system with a JARVIS-inspired HUD overlay built using OpenCV.

## Demo
![Demo](assets/demo.gif)

## Features
- Real-time face detection using Haar Cascade classifier
- Animated HUD corners around detected faces
- Scanning line animation
- FPS counter
- Video recording output

## Tech Stack
- Python
- OpenCV
- NumPy

## Setup

```bash
pip install -r requirements.txt
python jarvis.py
```

Press `Q` to quit. Output video saved to `output/jarvis_demo.mp4`.
